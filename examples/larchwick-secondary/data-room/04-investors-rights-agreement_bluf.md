# D04 - Investors' rights agreement (BLUF)

1. **What:** executed investors' rights agreement, 2026-03-02.
2. **Key facts:** information rights for a common holder start at 750,000 shares. Purchased common is not registrable. 180-day lockup binds transferees. The Strategic Investor has a board observer seat.
3. **Price impact:** a 600,000-share block gets no financials and no registration rights, so it is an unmonitored position.
4. **Conflicts:** the 750,000 threshold sits above the 600,000 block in the seller's offer.
5. **Ask:** an information side letter as a closing condition.
